# PDF 키워드 검색

내 컴퓨터의 **특정 폴더(및 하위 폴더)** 에 있는 PDF 내용을 키워드로 검색하는 웹 앱입니다.

- 탐색기에서 폴더를 선택합니다.
- PDF 파일은 **서버로 업로드되지 않고**, 브라우저에서만 읽습니다.
- 일치하는 파일명·페이지·문맥을 바로 표시하고, 클릭하면 해당 페이지가 열립니다.

## 로컬 실행 (Windows)

`run.bat`을 더블클릭하세요.

또는:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8001
```

브라우저: http://127.0.0.1:8001

## Render 클라우드

프론트엔드만 클라우드에 올려도 됩니다. 검색은 접속한 PC의 브라우저에서 로컬 폴더를 읽어 수행합니다.

1. GitHub 저장소를 Render Blueprint로 배포
2. 배포된 주소로 접속
3. **폴더 선택** → 키워드 검색

Chrome / Edge 권장 (`폴더 선택` API 지원).

## 사용법

1. **폴더 선택**으로 탐색기를 열어 PDF가 있는 폴더를 고릅니다.
2. 키워드를 입력하고 **검색**합니다.
3. 결과가 나오는 대로 표시됩니다. **중지** / **다시** 가능.
4. 파일명 또는 구문을 클릭하면 해당 PDF 페이지가 열립니다.

## 참고

- 텍스트가 포함된 PDF만 검색됩니다.
- 스캔본(이미지) PDF는 검색되지 않을 수 있습니다.
